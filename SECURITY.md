# Security Policy

## Supported Versions
The `main` branch is the only supported version.

## Reporting a Vulnerability
If you discover a security issue (e.g. an accidentally committed credential, an
unsafe default, or a collector that exposes private data), **do not open a
public issue.** Instead:

- Open a [private security advisory](https://github.com/MohamedHussien-zseeker/sourcewell/security/advisories/new), or
- Email the maintainer at ghostelite803@gmail.com with the subject `sourcewell security`.

You'll get a response within a few days. Once fixed, we'll credit you (with your
permission) in the release notes.

## What we will NOT do
- We will not help bypass paid licensing on third-party sites. Collectors only
  pull source the user is licensed for.
- We will not store or share any credential. The repo is credential-free by design.
